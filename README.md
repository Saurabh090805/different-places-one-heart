# Different Places, One Heart

A romantic, single-page website. The site is self-contained in `index.html`; it does not need a build step or package installation.

## Publish with GitHub Pages

The included GitHub Actions workflow publishes the site whenever a commit is pushed to `main`, and can also be run manually from the **Actions** tab.

1. In the repository on GitHub, open **Settings → Pages**.
2. Under **Build and deployment**, set **Source** to **GitHub Actions**.
3. Push this workflow to `main`, or run **Deploy website** from the **Actions** tab.
4. Once the workflow finishes, the website will be available at `https://saurabh090805.github.io/different-places-one-heart/`.

To preview it locally, open `index.html` in a browser.
